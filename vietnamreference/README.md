# Vietnam Heritage v2.0 — 1-to-1 Cultural Reference Pack & Macro-Map Spec Index

This folder holds the **15 reference photographs** supplied for `vietnam-heritage`, paired **1-to-1** with 15 dedicated architectural & cultural specifications (`specs/01_karst_sunset.md` through `specs/15_bach_dang_naval_fleet.md`) plus global direction (`specs/00_global_art_direction.md`) and machine-readable metadata (`specs/vietnam_reference_spec.json`).

> **Stage-Photo Translation Principle:** All 15 photographs capture a live cultural stage production with LED backdrops, audience silhouettes, seats, ceiling trusses, and stage lighting. Every spec preserves the authentic Vietnamese heritage composition, color drama, and structural craftsmanship while **rebuilding each scene at true 1:1 outdoor scale** on natural terrain, carved stone courtyards, and water—with **zero** theatre trusses, audience heads, seats, LED panel seams, stage floors, or subtitle text.

- **Dual-Ring Spatial Architecture:** Preserves every original Inner Core landmark (`r < 540m`) while placing **14 full-scale Outer Macro Cultural Sanctuaries** (`240m × 240m` to `480m × 380m` each) across the expanded territory.
